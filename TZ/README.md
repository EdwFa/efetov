# Прототип интерфейсов системы клинического исследования

## Как запустить
1. Распакуйте архив.
2. Откройте файл `index.html` в браузере.
3. Используйте тестовые учетные записи на экране авторизации.

## Тестовые логины
- Врач стационара: `stationary_doctor` / `Doctor123`
- Врач амбулатории: `ambulatory_doctor` / `Doctor123`
- Руководитель: `manager` / `Manager123`

## Что обновлено в v4
- В общем журнале добавлена сортировка по всем отображаемым столбцам.
- Добавлен столбец и фильтр «Дата и время создания».
- Для руководителя добавлена кнопка создания карточки пациента.
- Для руководителя при редактировании карточки, созданной другим пользователем, выводится подтверждающее модальное окно.
- Итоговая выгрузка и статистический срез формируют скачиваемый файл: Excel-выгрузка в структуре приложенного шаблона, CSV — дополнительная опция.
- Статистический срез учитывает фильтры общего журнала.
- Добавление, редактирование и удаление карточек сохраняется в localStorage браузера.
- Для возврата к исходным данным используйте кнопку «Сбросить демо-данные».

## Важно
Это кликабельный HTML-прототип, а не промышленная система. Все операции выполняются внутри браузера, данные сохраняются локально в `localStorage`.
